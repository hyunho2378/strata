# DESIGN.md

Strata 동해시 공공시설 기능연속성 관리 플랫폼의 디자인 방향이다.

시각 규칙의 단일 출처는 저장소 루트 `UI.md` 다. 색, 타이포, 간격, 크기, 반경, 그림자, 모션, 컴포넌트 상태, 검수 기준은 모두 그 문서에 있다.
실행 토큰은 `client/src/tokens.js` 이고 `tailwind.config.js` 가 그 값을 읽는다. `UI.md` 와 토큰 값이 다르면 작업을 멈추고 둘을 함께 맞춘다.
이 문서는 방향만 적는다. 수치를 여기에 다시 적지 않는다.

## 플랫폼

B형 반응형 웹이다. 320px 부터 3840px 까지 한 벌로 대응한다. 주 화면은 3D 지도라 화면 전체를 쓰고 패널은 지도 위에 뜬다. 768px 미만은 지도 아래 시트로 바꾼다. 배치 규칙은 `UI.md` 9장이다.

## 대상과 과업

동해시 담당 부서가 쓴다. 핵심 과업은 셋이다. 어느 시설의 어느 기능이 언제 멈추는지 보는 것, 멈춘 기능의 대체 시설을 찾는 것, 그 결과로 협조 공문을 만드는 것이다. 주민 공개 화면은 지금 이용할 수 있는 곳만 보여 준다.

## 방향

지도가 주인공이다. 화면 장식을 더하지 않고 지도 위 정보가 읽히게 만든다. 패널은 흰 면과 그림자 한 단계로만 떠 있고 테두리와 반투명을 쓰지 않는다. 기능 9색은 지도와 범례의 점에만 쓰고 나머지 UI 는 파랑과 빨강 두 계열만 쓴다.

## 아이콘과 일러스트

아이콘은 lucide-react 만 쓴다. 크기는 16, 20, 24, 32, 48 다섯 단계다. 이모지는 쓰지 않는다. 일러스트는 unDraw 를 빈 상태 화면에만 쓰고 색은 파랑 단색이나 흑백으로 맞춘다.

## 문구

화면 문구는 한국어다. 서술 문장은 마침표로 끝내고 명사로 끝나는 라벨과 버튼 이름에는 마침표를 찍지 않는다. 가운뎃점과 줄표는 쓰지 않는다. 내부 키와 개발 용어는 화면에 내보내지 않는다. 개인 담당자 이름과 전화번호는 넣지 않고 부서명만 쓴다.

## 접근성

글자 대비 4.5:1, 큰 글자와 UI 요소 3:1 이상이다. 키보드만으로 모든 기능에 닿고 포커스 표시는 `UI.md` 7장의 한 가지 방식만 쓴다. `prefers-reduced-motion`, `prefers-reduced-transparency`, `prefers-contrast` 를 존중한다.
