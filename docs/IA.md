# IA.md

## 화면 구조

```
담당자 셸(아이콘 레일 + 메뉴 칸 + 상단 띠 + 둥근 흰 판)
/                      현황판
  오늘 지정 공백 | 이번 달 운영 중단 일정 | 확인할 일
  대체 시설이 먼 곳 | 역할별 시설 수 | 오늘 운영 상태
/board                 상황판(본문 안 큰 카드에 3D 지도)
  왼쪽  역할 9종 거르기, 범례, 지금 현황
  오른쪽 시설 상세
  아래  시간축(슬라이더, 재생), 특보 고르기(평시, 한파, 호우, 해일)
  위    시설 검색, 대표 장면 이동, 그림 품질
/facilities            시설(검색, 역할 칩, 목록 + 지도)
/facilities/:id        시설 상세(홈, 운영 일정, 대체 시설, 정보)
/review                판독함(운영 중단 공지 확인 줄, 판독 결과와 원문 출처)
/facility/:id/inside   건물 층 보기
/docs                  문서함
  /docs/doc/:id        한글 문서 편집기
  /docs/sheet/:id      시트 편집기
  /docs/form/:id       설문지 편집기

공개 셸(위쪽 메뉴 + 같은 여백과 카드)
/public                주민 공개 화면(오늘 상태 요약, 검색, 역할 칩, 시설 카드)
/f/:id                 설문 응답 화면(링크로 연다)
```

## 자료

- `client/src/data/strata.json` 시설, 역할, 운영 상태, 중단 일정, 대체 시설. 자료 담당이 만든다.
- `client/src/data/scenes.json` 대표 장면. 없으면 장면 단추를 숨긴다.
- `client/src/data/inside.json` 과 `client/public/inside/<id>.webp` 시설 속 보기. 없으면 빈 상태 화면을 보인다.

자료 파일은 `lib/strataData.js` 가 `import.meta.glob` 으로 있는 것만 읽는다. 없으면 빈 상태로 둔다.

## 화면 비율

상황판의 지도는 본문 안의 큰 카드 하나다. 전체 화면을 덮지 않는다. 왼쪽 역할 패널 288, 오른쪽 시설 상세 360(1440 이상 384)이고 768px 미만에서는 아래 시트로 바꾼다.
시설 화면은 왼쪽 목록 384와 오른쪽 지도 카드로 나눈다. 시설을 고르면 지도 자리에 같은 상세가 열린다.
