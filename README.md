# Strata

동해시 공공시설 기능연속성 관리 플랫폼이다. 공공시설 한 곳이 여러 기능을 함께 맡고 있어, 한 시설이 멈추면 여러 기능이 동시에 멈춘다. Strata 는 시설 위에 기능 층을 쌓아 보여 주고, 멈추는 기간과 대신 쓸 시설을 같은 화면에서 확인하게 한다.

## 화면

| 경로 | 화면 |
| --- | --- |
| `/` | 현황판. 오늘 비는 역할, 이번 달 운영 중단 일정, 확인할 일 |
| `/board` | 상황판. 동해 3D 지도, 역할 레이어, 시간축, 건물 층 나눠 보기 |
| `/facilities` | 시설 목록과 시설 상세 |
| `/review` | 판독함. AI가 읽은 운영 중단 공지 확인 대기열 |
| `/docs` | 문서함. 협조 공문과 안내문, 한글 문서 내보내기 |
| `/public` | 주민 공개 화면 |

## 개발

```
cd client
npm install
npx vite
```

## 문서

- `docs/CONTRACT.md` 병렬 작업 계약(파일 소유, 자료 계약, 3D 엔진 계약)
- `docs/DESIGN.md` 디자인 방향과 토큰
- `docs/IA.md` 화면 구조
- `docs/ROUTES.md` 라우팅
